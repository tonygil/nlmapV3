What it does

The improvement loop made automatic

After running the matcher you typically end up with a batch of unmapped URLs. To improve the match rate you need to figure out why each URL didn't match, decide on a fix (add a synonym? update category mapping?), apply it, and re-run. Without tooling this is slow and repetitive.

The Campaign Assistant automates the diagnosis step. It reads your match output file, looks at the Unmapped_Reason column, checks the Keyword Recommendations sheet, and groups the problems into ranked suggestions — biggest wins first.

Three root causes, three fix types
● CATEGORY MAP

A Salesforce product code (e.g. Adsolut_KMO_beheer) is not in category_mapping.json. The matcher can't tell which taxonomy product it belongs to, so all those articles are excluded.

Fix: map the Salesforce code to a taxonomy product.

● SYNONYM

Keywords extracted from the article nearly matched a taxonomy topic but fell just below the fuzzy threshold. The topic and keyword are semantically linked but worded differently.

Fix: add the keyword as a synonym for the topic.

● DATA ISSUE

The article has no extractable keywords at all — Title, Summary, and Description columns are all empty. The matcher has nothing to work with.

Fix: populate the content columns in the source file.

● NO MATCH

Keywords exist but no taxonomy topic reached the similarity threshold. This can mean the topic hasn't been covered by synonyms yet, or the threshold needs adjusting.

Fix: add synonyms, or lower the threshold on the Setup tab.

ℹ️
Estimated gain is not guaranteed. The number shown on each suggestion card is the count of currently-unmapped URLs affected by that fix. After re-running, the actual uplift may be slightly different because some URLs could still be blocked by another reason.

Step-by-step workflow

From running the matcher to hitting your target

1
Run the matcher (Setup tab)

Make sure the output filename contains a timestamp so previous results aren't overwritten. The output file must include the Keyword Recommendations sheet — this happens automatically unless you explicitly disabled it.

2
Switch to Campaign Assistant tab

The Match File field is auto-populated if you ran the matcher in this session. Otherwise click Auto-fill or Browse to find the file. Confirm the Country is correct and set your Target percentage.

3
Click Analyse

The status label shows "Analysing…" while working. For a typical 1,500-URL file this takes a few seconds. The stats strip and suggestion cards appear when done.

4
Review and apply suggestions top-to-bottom

Start with the highest-gain cards (they appear first). For each one: read the description, confirm the fix looks correct, then click ✓ Apply Fix or ✓ Apply Synonyms. The button turns grey and shows "Applied" when done. Use Skip to hide cards you want to ignore.

5
Click Re-run Matcher

At the bottom of the tab. This switches you to the Setup tab, triggers a new matcher run with the same settings, and after completion automatically re-analyses the new output.

6
Review the delta

The status label shows the before/after comparison (e.g. "Re-run: 72.4% ↑4.3pp +76 URLs mapped") and the tab switches back to Campaign Assistant automatically. The stats strip now shows your new match rate. Repeat from step 4 until you reach the target.

Applying fixes in detail

What happens when you click Apply, and how to undo

What Apply Fix does (Category Mapping)

Read category_mapping.json
Loads the current file from countries/{CC}/category_mapping.json
Create timestamped backup
Copies file to category_mapping_backup_YYYYMMDD_HHMMSS.json in the same folder
Write new entry
Adds "Adsolut_KMO_beheer": "Adsolut boekhouding" (or null for Filter out)
Save file
Writes the updated JSON back with 2-space indentation

What Apply Synonyms does

Read synonyms.json
Loads from countries/{CC}/synonyms.json
Create timestamped backup
Saves synonyms_backup_YYYYMMDD_HHMMSS.json first
Append new synonyms
Merges the suggested keywords into the synonyms → {TopicName} list; skips any already present
Save file
Writes the updated JSON. The product_synonyms section and all other topics are preserved unchanged.

How to undo a change

Every apply operation creates a backup file in the same folder as the JSON it modifies. To undo:

  1. Open File Explorer and navigate to countries/{CC}/
  2. Find the backup file: synonyms_backup_20260223_143022.json or category_mapping_backup_20260223_143022.json
  3. Rename the current file (e.g. append _bad)
  4. Rename the backup to the original name (synonyms.json or category_mapping.json)
  5. Re-run the matcher
💡
Multiple backups accumulate over time. Old backups are harmless but you can delete them to tidy up. The Category Mapping Editor tab also provides a direct interface to review and remove individual entries without touching the JSON file.

Checking what was written

After applying a fix, you can inspect the result directly:

  • Category Mapping: Switch to the Category Mapping tab and click Load — your new entry will appear in the table.
  • Synonyms: Switch to the Synonym Editor tab, select the topic from the dropdown — the new keywords will be in the list.

Re-running and the delta view

Triggering a new run and reading the before/after comparison

After applying fixes, click Re-run Matcher at the bottom of the Campaign Assistant tab. This does the following automatically:

1
Saves baseline stats

The current match rate and mapped count are recorded so they can be compared against the new run.

2
Switches to Setup tab and triggers run

You will see the progress log on the Console tab as normal. The matcher uses whatever settings are currently on the Setup tab — same threshold, same files.

3
Automatically re-analyses the new output

Once the run completes, the Campaign Assistant silently reads the new file, computes fresh stats and suggestions, and updates the display.

4
Shows the delta and switches back

The tab switches back to Campaign Assistant. The status label shows the comparison: Re-run: 72.4% ↑4.3pp (+76 URLs mapped). The stats strip updates to show the new numbers.

⚠️
Do not change the Setup tab settings between clicking Re-run Matcher and waiting for the run to complete. The re-run uses the current Setup tab state. If you need to change settings, do so on the Setup tab before clicking Re-run Matcher.

Running analysis manually (without Re-run)

You can also analyse any previous match file at any time — just change the Match File path and click Analyse again. This is useful for comparing two different output files side by side (open two sessions of the app) or for going back to a historical run.

FAQ & Troubleshooting

Common questions and what to do about them

Q The Keyword Recommendations sheet is missing — will the assistant still work?

Yes. If the Keyword Recommendations sheet is absent from the match file, the assistant skips the synonym suggestions entirely and only shows Category Mapping, Data Issue, and No Match cards. To get synonym suggestions, re-run the matcher — the sheet is generated automatically.

Q The "Map to" dropdown is empty — how do I find the right product name?

The dropdown is populated from the Category Mapping tab data (if loaded) or from the taxonomy file. Try opening the Category Mapping tab and clicking Load first — the assistant will then have access to the product list. Alternatively, open the taxonomy file and look for the correct Product column value. You can also type the product name directly into the dropdown field.

Q A category mapping suggestion appeared even though that product is already in category_mapping.json — why?

This can happen if the Salesforce product code has different capitalisation or whitespace than the key in category_mapping.json. The assistant matches keys case-insensitively, but check the JSON file directly if you see this. Also check that the entry isn't under a _comment key (those are ignored during matching).

Q I applied synonyms but the next run didn't improve those URLs — what happened?

A few possibilities:

1. Synonym didn't match: The synonym is added to synonyms.json under the exact topic name from the Keyword Recommendations sheet. If that topic name doesn't match exactly what's in the taxonomy file, the expansion won't fire. Open the Synonym Editor and check the topic key.

2. Product filter still blocking: If the URL also has a product mismatch, matching the topic still isn't enough — fix the category mapping too.

3. Score still below threshold: The synonym adds a new candidate string for fuzzy matching, but if the match still scores below 80%, it won't appear. Try lowering the threshold, or check whether the keyword is too different from the synonym.

Q Can I apply multiple fixes and then do a single re-run?

Yes — this is the recommended approach. Apply all the fixes you want (click Apply on multiple cards), then click Re-run Matcher once. The delta view will show the combined uplift from all your changes.

Q The status label shows an error after clicking Analyse — what do I do?

The most common causes are:

  • "File not found" — the file has been moved or renamed. Use Browse to locate it.
  • "Error reading file: … sheet 'Results'" — the file doesn't have a Results sheet. Make sure you're pointing at a match output file (taxonomy_match_*.xlsx), not the taxonomy file or semantic carriers file.
  • File is open in Excel — close Excel and try again.
Q The match rate shown doesn't match what I see in the Gap Analysis report — why?

Both use per-unique-URL counting. Small differences can occur if:

  • The Gap Analysis report was generated from a different run of the matcher than the file you're analysing in the Campaign Assistant.
  • The Gap Analysis report uses its own logic for "Progress" tracking (stored in gap_analysis_progress.json) which may include a baseline from an earlier run.

The Campaign Assistant always reads directly from the Results sheet you provide — it does not use gap_analysis_progress.json.

Q How do I know which suggestions to apply and which to Skip?

Apply: suggestions where the fix is clearly correct — e.g. a Salesforce product code you recognise and know maps to a specific product, or synonyms that are obviously related to the topic (e.g. "oss aangifte belgie" → "OSS aangifte").

Skip: suggestions that look ambiguous, where the pre-filled product looks wrong, or where the suggested synonyms include generic words that might cause false matches elsewhere. You can always apply these manually via the Synonym Editor or Category Mapping tab after further review.

Q I accidentally applied the wrong product in a category mapping — how do I fix it?

Open the Category Mapping tab, find the entry, double-click to edit it and change the target product, then click Save. No backup is needed since the Category Mapping tab has its own save/load cycle. Alternatively, restore from the timestamped backup JSON file in countries/{CC}/.
