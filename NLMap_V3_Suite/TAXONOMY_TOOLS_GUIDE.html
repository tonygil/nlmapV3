Part One
Stakeholder Overview
The problem, the solution, what it costs, and what it delivers

The Problem: A Language Gap

The Taxonomy Mapper automatically assigns support articles to taxonomy categories — BTW aangifte, Jaarrekening, CODA bestanden, Peppol E-invoicing and so on. It works by comparing keywords extracted from each article against the formal category names in the taxonomy using a similarity score.

The challenge is that article content uses everyday language while the taxonomy uses precise, formal names. If an article discusses "aangifte" but the category is called "BTW aangifte", the tool scores them at only 62% — just below the 80% minimum. The article goes unmapped, receiving no category tag, even though any reader would immediately recognise it belongs to BTW aangifte.

A synonym bridges this gap. Adding "aangifte" as a synonym for BTW aangifte tells the system they mean the same thing. Every article mentioning "aangifte" is then correctly mapped — automatically, on every future run.

💡 A low match rate is not a content problem

It almost always means synonyms have not yet been built up for that country's language and product terminology. The articles are correct — the bridge between content language and taxonomy language is simply missing.

Part Two
Gap Analysis Dashboard
gap_analysis_dashboard.html — your diagnostic view

What It Is

The Gap Analysis Dashboard reads a TAXONOMY_GAP_ANALYSIS_REPORT*.xlsx file and turns it into an interactive visual overview of your taxonomy coverage. It answers the question: "Where am I and what do I need to fix?"

It is the starting point for every improvement session — open it first, understand the current state, then move to the Synonym Review Tool to act on what you find.

What File to Load

📂 File: TAXONOMY_GAP_ANALYSIS_REPORT*.xlsx

Generate it from the GUI: Reports tab → Taxonomy Gap Analysis Report → select your match output and taxonomy files → Generate.

Or from the command line: python generate_taxonomy_gap_analysis.py

Not the match output file. Not the semantic input file. The Gap Analysis report specifically.

Reading Each Section

The Match Rate Ring

The large ring chart in the hero panel shows the current match rate as a percentage. The colour indicates health:

ColourRangeWhat it means

Never-Matched Topics

These are taxonomy categories that have never matched a single article across all runs. They represent blind spots — the taxonomy says these topics exist, but no article has ever been assigned to them.

This can mean one of two things:

  • The topic needs synonyms — the terminology in articles doesn't match the formal category name closely enough. Fix: add synonyms via the Synonym Review Tool or Synonym Assistant.
  • The topic may no longer be relevant — no articles about this subject exist in the content set. Fix: raise with the taxonomy owner for review.

Phantom Topics

Topics appearing in match results that do not exist in the current taxonomy. These are a data quality signal — they usually indicate the match was run against an older version of the taxonomy, or a topic was renamed or removed.

⚠ Phantom topics should be zero

If you see phantom topics, re-run the matcher using the current taxonomy file and regenerate the Gap Analysis. Do not add synonyms until the taxonomy file is confirmed correct.

Match Rate Over Time

Every time you generate a Gap Analysis report, the run is recorded in a progress file (gap_analysis_progress.json). The dashboard charts these runs as a timeline, showing how the match rate, never-matched count, and phantom count change across sessions.

Use this chart to measure the impact of each synonym session. A run immediately after applying synonyms should show a clear step up in the match rate.

Synonym Recommendations Sheet

Inside the Gap Analysis report Excel file, the Synonym Recommendations sheet suggests specific keywords from the semantic file that closely match never-matched topics. This complements the Synonym Review Tool — where the Review Tool focuses on keywords that nearly matched topics during the last run, the Synonym Recommendations focuses on keywords that could help never-matched topics.

Part Three
Synonym Review Tool
synonym_review.html — your action view

What It Is

Where the Gap Analysis Dashboard tells you what needs fixing, the Synonym Review Tool is how you fix it. It reads the Keyword Recommendations sheet from the most recent match output and presents every near-miss keyword in a reviewable list — sorted by how close they were to matching and how many articles they affected.

You review each entry, verify it makes sense by opening the sample article URLs, approve the ones that are genuine synonyms, and export them in a single click. The approved synonyms are applied to the system and take effect on the very next match run.

What File to Load

📂 File: taxonomy_match_*.xlsx — the match output

Load the file produced by the most recent Taxonomy Mapper run — for example taxonomy_match_BE_19thFeb_BE.xlsx (BE) or taxonomy_match_NL_*.xlsx (NL) or taxonomy_match_SE_*.xlsx (SE).

It must contain a Keyword Recommendations sheet. This sheet is included automatically in every match run — no extra steps required.

Not the Gap Analysis report. Not the semantic input file. The match output.

Understanding Priorities

Every near-miss keyword is assigned a priority based on how close it was to the threshold and how many articles it affected. Priorities are calculated relative to your match threshold (default 80%), so they shift automatically if the threshold changes.

PriorityCriteriaWhat it means in practiceTypical action
HIGHScore ≥ 75% AND 3+ articlesThis keyword is very close to a category name and appears frequently. One approval unlocks multiple articles.Approve unless URLs show it is navigation noise
MEDIUMScore ≥ 65% AND 2+ articles, OR product-filtered, OR 5+ articles with no close matchWorth reviewing — either a reasonable synonym candidate or a sign of a product mapping issue.Check the URLs and the Action column before deciding
LOWScore ≥ 50%A speculative match. Rarely worth approving unless you recognise the term.Ignore unless targeting a specific niche topic
NOISEEverything elseGeneric stopwords, single characters, UI chrome. Already filtered — never shown.No action needed

Step-by-Step Guide

1
Open the tool
Double-click synonym_review.html in the project folder. Opens in your browser — no login, no installation.
2
Drop the match file onto the landing screen
Drag taxonomy_match_BE_*.xlsx onto the drop zone. The tool validates that it contains a Keyword Recommendations sheet and tells you immediately if you have loaded the wrong file.
3
Set your filters — work one product at a time
Click the HIGH priority pill. Use the Product dropdown to focus on one product. Tick New synonyms only to hide keywords already registered — this keeps the list clean and focused.
4
Review each item — open the URL expander
Click the blue URL count button on any row to expand a list of sample articles. Open one or two and ask: Is this article genuinely about the suggested category? Use the decision tree on the next page to guide your answer.
5
Select your approvals
Tick the checkbox on each row you approve. Use Select All HIGH as a starting point, then untick any you want to reject. The footer shows the running count of selected items.
6
Export Approved Synonyms
Click the green Export Approved Synonyms (N) button. A file named synonym_patch_BE_2026-02-19.json downloads to your browser's downloads folder.
7
Apply the patch
Open a command prompt in the project folder and run:
python apply_synonym_patch.py -i synonym_patch_BE_2026-02-19.json
python apply_synonym_patch.py -i synonym_patch_NL_2026-02-19.json  (NL)
python apply_synonym_patch.py -i synonym_patch_SE_2026-02-19.json  (SE)

The country is auto-detected from the filename. To preview without making any changes: add --dry-run
A timestamped backup of the synonyms file is created automatically before any change.
8
Re-run the matcher and regenerate the Gap Analysis
Run the taxonomy matcher for the same country via the GUI, or CLI:
python taxonomy_matcher.py -c BE -t 80  (Belgium)
python taxonomy_matcher.py -c NL -t 80  (Netherlands)
python taxonomy_matcher.py -c SE -t 80  (Sweden)

Then regenerate the Gap Analysis report and open the dashboard to see the new match rate recorded in the progress chart.

Approve vs Reject — Quick Reference

✅ Approve these
  • A shorter form of the category name ("btw aangifte" for BTW aangifte)
  • A longer phrase clearly meaning the same thing ("jaarrekening opmaken")
  • A product-specific prefix + topic ("adsolut fiscaal dossier")
  • A consistent abbreviation ("coda import" for CODA bestanden)
  • 2+ sample URLs clearly about the suggested category
❌ Reject these
  • UI phrases ("artikel lees", "raadpleeg dit artikel", "klik hier")
  • Navigation phrases ("alle artikelen", "een overzicht van")
  • Brand / footer text ("wolters kluwer", "kluwer taa software")
  • Single generic words ("beheer", "aanmaken", "instelling")
  • Frequency 1–2 · or URLs don't relate to the category
Part Four
The Improvement Loop
How the two tools work together over time

A Typical Improvement Session

1
Open Gap Analysis Dashboard — understand where you are
Check the current match rate, the never-matched topic count, and the progress chart. Identify which products have the most never-matched topics — these are your focus areas for today's session.
2
Open Synonym Review Tool — work through HIGH items by product
Load the most recent match output. Filter to HIGH priority. Use the Product dropdown to work through one product at a time. Verify URLs for each item. Approve genuine synonyms, reject UI chrome and navigation phrases.
3
Export and apply the patch
Export your approved synonyms. Run apply_synonym_patch.py. The synonyms are live immediately — no restart required.
4
Re-run the matcher and regenerate the Gap Analysis
Run the taxonomy matcher for the same country. Then regenerate the Gap Analysis report. The new match rate appears in the progress chart — confirming the impact of this session's work.
5
Repeat until 80%
Each iteration surfaces new near-misses at a slightly higher score band. The HIGH items become fewer per session as coverage improves. Three to four sessions typically moves a country from minimal synonyms to 80% match rate.

When You Have Run Out of HIGH Items

If no HIGH items remain but the match rate is still below 80%:

  1. Open the Gap Analysis Dashboard — check the Never-Matched Topics list. Topics that never matched any article often need synonyms that weren't in the content at all.
  2. Use the Synonym Assistant tab in the GUI (load the semantic file + taxonomy, run Combined analysis) — it suggests keywords from URL paths for never-matched topics, which the Synonym Review Tool would not surface.
  3. Check the Unmapped_Reason column for remaining unmapped articles — if the majority say "Product filter excluded", the remaining block is in product assignment rather than synonyms.

Common Questions

I applied synonyms but the match rate didn't change. Why?
The most common reason is that the remaining unmapped articles have a different root cause — product filtering or missing keywords — rather than near-miss scoring. Filter Domain = UNMAPPED in the match output and read the Unmapped_Reason column. See Decision Tree B in Part Three.
I approved something by mistake. Can I undo it?
Yes. Every time apply_synonym_patch.py runs it creates a timestamped backup automatically. Rename synonyms_backup_YYYYMMDD_HHMMSS.json back to synonyms.json in the countries/BE/ folder to restore the previous state.
A keyword I approved is now appearing on the wrong articles.
The keyword was too generic and matches multiple categories. Open countries/BE/synonyms.json, find the topic, remove the keyword from its list, and re-run the matcher.
There are 1,864 MEDIUM items. Do I need to review all of them?
No. Focus on HIGH first — they give the biggest return per item reviewed. For MEDIUM, filter the Freq column to 5 or above and work through those. LOW items can generally be ignored unless you are targeting a very specific niche topic.
When should I use the Gap Analysis Synonym Recommendations versus the Synonym Review Tool?
The Synonym Review Tool surfaces near-misses from the most recent match run — keywords that nearly matched a topic but fell short. The Gap Analysis Synonym Recommendations focus specifically on topics that have never matched at all and suggests keywords from the full semantic file that could unlock them. Both are complementary — use the Review Tool first (faster, higher impact), then the Gap Analysis recommendations for topics that still have zero matches.
